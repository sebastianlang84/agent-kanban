Deployment · agent-kanban

One board host, many guests

kb authorize adds each guest key to the host's authorized_keys as command="<kb> serve --installation <id>",restrict, so the key runs nothing but kb serve. The host has no server process; ssh starts kb serve per request. A start, stop or end hook event that misses the host within 1 s stays in the guest's spool; the next such hook or kb spool --drain sends it. Curator actions run only on the host. Details: README, "Host and guests".
