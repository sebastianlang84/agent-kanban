A request between two agent sessions

The prompt hook lists, at each user prompt, unclaimed requests addressed to the session's name or to any, and replies to requests a session of that name opened; it reminds the opener once per latest reply to kb close an answered request, and a session once per claim to kb close the tickets it holds. kb close is refused while a request has no reply; until the close the board flags it answered.
